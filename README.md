# Personal Todo List

A simple personal to-do list app built with HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as complete
- Delete tasks
- Clear completed tasks
- Keep tasks saved in the browser using localStorage
- Responsive layout for desktop and mobile

## Project Structure

- `index.html` — page structure
- `style.css` — styling and layout
- `script.js` — task logic and browser storage

## Run the Project

You can open `index.html` directly in a browser, or run a small local server:

```bash
cd "e:\Data Analytics Course\Git\New folder\todo-list"
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

This project stores data in the browser's local storage, so your tasks remain available when you reload the page.
